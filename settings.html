Image Embeds Expressions Use {{img::name}} in chat

1. Both Character and User expressions are stored per-character.
2. Character expressions auto-inject when the character speaks.
3. User expressions auto-inject when you (the user) send messages.
4. Expressions are injected using placeholder: {{img::expression_name}}
5. For multi-character chats, you can name them like: NameChar/pose or NameChar_pose (supports \, -, | separators)
e.g., Evelyn/smile, Violet-huhu, Miko|focused
